## How to run this ?

1. **Clone this repo**

```bash
git clone https://github.com/mehedi-codes/baaperbank.git
```

2. **Open baaperbank in vscode**

```pwsh
code baaperbank
```

3. **Open index.html and Right click on the editor**

4. **Click "Open with Live Server".**

5. **Project should be up and running in your browser.**
